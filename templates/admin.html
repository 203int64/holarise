Mọi mã xác minh thẻ <meta> và beacon sẽ tự động được bơm ở tầng Cloudflare Edge (không cần sửa code hay rebuild). Toàn bộ khóa bí mật được ẩn hoàn toàn sau khi lưu.

Tự động gắn thẻ <meta name="google-site-verification"> vào mọi trang công khai.
Hoặc import thẳng từ Google Search Console trong Bing Webmaster Tools.
Trạng thái: Chưa gắn khóa riêng (vẫn quét được bằng hạn mức công khai).
Dùng sc-domain:holarise.org (Domain property) hoặc https://holarise.org/ (URL prefix).
Trạng thái: Chưa kết nối GSC API. Tạo Service Account trên Google Cloud → bật Search Console API → thêm email Service Account làm người dùng Restricted trong GSC → dán nội dung file JSON vào đây.

Cài HolaRise CMS về màn hình chính

Mở nhanh trang Điều phối như một ứng dụng độc lập, không bị vướng thanh địa chỉ trình duyệt.

  1. Chạm biểu tượng Chia sẻ ở thanh dưới cùng Safari.
  2. Cuộn xuống chọn Thêm vào Màn hình chính, sau đó bấm Thêm.

Mở bằng Safari hoặc Chrome để cài đặt

Trình duyệt mở từ Zalo hoặc Messenger chưa hỗ trợ cài ứng dụng trực tiếp.

  1. Bấm biểu tượng menu ⋯ ở góc màn hình.
  2. Chọn Mở bằng Safari (iPhone) hoặc Mở bằng Chrome (Android), sau đó bấm Cài ứng dụng.
